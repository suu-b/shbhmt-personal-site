# Otto

Otto is the CMS for my personal site. It provides these capabilities.

1. View existing articles.
2. Create and Publish new articles.
3. Delete Existing articles.

From a technical standpoint, it is an electron app with a rudimentary, opinionated editor and a deployment pipeline that makes use of Fine-grained GitHub PAT to commit and push changes to the main branch of this repostitory using octokit.
