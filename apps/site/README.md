# Preface

I call my personal site a preface because it is a space where I intend to log my intellectual journey.

From a technical standpoint, it is an astro site. Earlier, it was a regular react app, but I switched to astro given its content-focused site capabilities. For consistent styling I am making use of shared vanilla css styles and tailwind components from the shared package.
